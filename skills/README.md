# AgentDeck Skills

本目录存放与 AgentDeck Desktop **同源维护**的 Agent Skills。

| Skill | 用途 |
|-------|------|
| [`agentdeck-services`](./agentdeck-services/) | 本机开发服务的注册、启停、日志与健康检查（REST `127.0.0.1:8788`） |

**安装 / 更新入口（GitHub）：**  
https://raw.githubusercontent.com/lepfinder/AgentDeck/main/skills/agentdeck-services/README.md

本地 Cursor / Agents 也可将 `~/.cursor/skills/<name>` 或 `~/.agents/skills/<name>` **符号链接**到本目录对应子目录，`git pull` 即更新。
