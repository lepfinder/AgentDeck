AgentDeck REST API v0.2.4

提供给外部脚本、CLI、Raycast、自动化管线与大盘集成的只读/控制服务

API 服务运行中
http://127.0.0.1:8788
🔒 鉴权说明: 免 Token 校验 (No Token Required)

当前服务严格监听在本机回环网卡 127.0.0.1:8788，仅限本机进程/脚本直接调用，外部网络无法直连，无需在请求头传递 Authorization 鉴权。

核心概览与指标
GET /health
服务健康与核心可用性探测

返回应用版本、各多源 AI 助手数据源探测状态与基本大盘总数。

curl http://127.0.0.1:8788/health
在新标签页中执行测试 →
GET /api/stats
全局会话、消息统计与多智能体分布

获取全量会话数、用户消息总数、Antigravity / Cursor / Claude / Codex 占比及工作区统计。

curl http://127.0.0.1:8788/api/stats
在新标签页中执行测试 →
工作区与研发深度画像
GET /api/workspaces
已索引的项目工作区列表
参数名类型说明
qstring (可选)按项目名称或目录模糊过滤
curl http://127.0.0.1:8788/api/workspaces
在新标签页中执行测试 →
GET /api/workspaces/detail
指定工作区 365 天研发热力图与打卡明细
参数名类型说明
workspacestring (必填)工作区绝对路径
curl "http://127.0.0.1:8788/api/workspaces/detail?workspace=/Users/xiyangxie/workspace/personal/AgentDeck"
智能体会话与消息流
GET /api/conversations
会话列表查询（支持过滤与分页）
参数名类型说明
workspacestring (可选)限定工作区
sourcestring (可选)限定工具源 (antigravity, cursor, claude, codex)
limit / offsetnumber分页参数 (默认 limit=50)
curl "http://127.0.0.1:8788/api/conversations?limit=10"
在新标签页中执行测试 →
GET /api/conversations/:id
单个会话全量消息流、思考链与附图
curl http://127.0.0.1:8788/api/conversations/{conversation_id}
GET /api/search
全局消息全文检索与代码关键词定位
参数名类型说明
qstring (必填)搜索关键词
limitnumber结果上限 (默认 50)
curl "http://127.0.0.1:8788/api/search?q=backup"
媒体资源与控制接口
GET /media/:source/:conv_id/:filename
本地分层归档媒体图片静态分发

安全静态访问本地持久化归档的图片资产（支持 PNG/JPEG/WEBP/GIF）。

curl -I http://127.0.0.1:8788/media/antigravity/{conv_id}/{image.png}
POST /api/sync
即时触发多源数据增量同步

通知后端立即扫描全部 AI 助手数据源目录并增量解析落盘。

curl -X POST http://127.0.0.1:8788/api/sync
