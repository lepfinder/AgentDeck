免 Token 鉴权说明 (No Token Required)

本服务严格监听在当前 Mac 本机回环网卡 127.0.0.1:8788，外部网络设备无法直连访问。 因此无需在请求头附加 Authorization Token 鉴权，直接发起 HTTP 请求即可。
